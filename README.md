
# Animalese Text-to-Speech

A mini app that converts typed text into cute, fast-paced “Animalese” sounds, similar to the voices of characters in *Animal Crossing*.  

**Netlify Deployed app** [https://text-to-speech-synthesizer.netlify.app/](https://text-to-speech-synthesizer.netlify.app/)

## Features

- Converts typed text into sounds using individual alphabet audio files.
- Lightweight: just HTML, CSS, and JavaScript.
- Fun and easy to integrate into web projects or demos.

## Project Structure


- `index.html` — main page with input and play button.  
- `styles.css` — basic styling for input and controls.  
- `script.js` — logic to map letters to sounds and play them.  
- `sounds/` — folder containing the alphabet sound files.

## How to Use

1. Clone or download the repository.  
2. Open `index.html` in a browser.  
3. Type any text in the input field.  
4. Click the **Play** button to hear it in Animalese style!  

## Example

Type: `hello`  
You’ll hear a sequence of sounds corresponding to `h`, `e`, `l`, `l`, `o`.  

## Technologies

- HTML  
- CSS  
- JavaScript
